# elite-hud

Небольшой оверлей для **Elite Dangerous**: читает журнал игры и показывает одну
строку полезной информации у верхнего края экрана — поверх игры, не перехватывая
клики и не забирая фокус.

```
`[◎] Achenar 15 тел │ [⚖] баланс 4.2B │ Panther Clipper Mk II (макс: 40 ly | тек: 33 ly) │ [▤] 199/1232 т │ [◈] миссии 3/20`
`[✦] след. Synuefe GX-K c24-11 (K, 5)  │  [🚚] V3G-N1H груз 7001/25000 т · бронь 12857`
`[★] Blu Theia AV-F d11-1  ·  открыта: Madne5 14.09.2026  ·  заправка: да  ·  трафик: сутки 0, неделя 1, всего 1`
`[🌿] +3 Вольфрам (Сырьевой, Редкость: 3)  Всего: 79`
```

---

## Важно: режим окна в игре

**Оверлей виден только в оконном режиме без рамок.** В настройках игры:

```
Options → Graphics → Display Mode → Borderless
```

В режиме **Exclusive Fullscreen** оверлея не будет: игра забирает экран целиком, и
поверх неё не рисуется ни одно окно — это ограничение Windows, а не программы.
Режим **Windowed** тоже работает, но игра тогда в окне.

Borderless даёт ту же картинку на весь экран, что и Fullscreen, так что терять
ничего не придётся. Разрешение и частота обновления остаются любыми.

## Установка

Нужны **Windows 10 или 11**. Python и что-либо ещё ставить не надо: сборка
содержит всё внутри.

### Установщик (рекомендуется)

1. Скачайте `elite-hud-setup-<версия>.exe` со страницы
   [последнего релиза](https://github.com/madne5/edhud/releases/latest).
2. Запустите. Windows покажет «Windows protected your PC» — нажмите **More info →
   Run anyway**. Так бывает у любого установщика без платной подписи разработчика;
   сверить файл можно по `SHA256SUMS.txt` из того же релиза.
3. Галочка «запускать вместе с Windows» — по желанию, чтобы оверлей появлялся сам.
4. Программа запустится и покажет строку поверх игры.

Обновления приходят сами: новая версия скачивается и ставится при следующем
запуске. Проверить вручную — **трей → Проверить обновления**.

### Портативная сборка

`elite-hud-<версия>-win64.zip` — распакуйте в любую папку и запустите
`elite-hud.exe`. Настройки при этом всё равно живут в профиле пользователя
(`%APPDATA%\elite-hud`), чтобы обновление их не потеряло.

## Что показывает

### Верхняя строка — постоянная сводка

| Блок | Что показывает |
|---|---|
| **ФК** | обратный отсчёт до прыжка флотоносца и целевая система — если прыжок запланирован; «готов через 04:12» во время перезарядки |
| **система** | имя системы и количество тел |
| **баланс** | кредиты; зелёным, пока файл статуса их обновляет |
| **корабль** | модель корабля (Caspian Explorer, Panther Clipper Mk II) и дальность прыжка: максимальная и текущая с грузом |
| **трюм** | занято/всего в тоннах; краснеет, когда трюм полон |
| **миссии** | сколько миссий взято из лимита |
| **груз по миссиям** | сколько груза по активным миссиям ещё «взять» и сколько «сдать»: `взять 416 т · сдать 612 т` |

### Нижняя строка

| Блок | Что показывает |
|---|---|
| **цель прыжка** | следующая система, класс звезды, остаток прыжков |
| **флотоносцы** | по блоку на каждый носитель: позывной, **фактически загруженный груз** и зарезервированное место (`V3G-N1H груз 7001/25000 т · бронь 12857`). Иконка зелёная, если стыковка открыта всем, оранжевая — если доступ ограничен |
| **режим игры** | `ОТКРЫТАЯ ИГРА`, `СОЛО`, `ЧАСТНАЯ СЕССИЯ` |
| **розыск** | неразумность и неоплаченные штрафы; у чистого командира блок скрыт |

### Строка EDSM о цели прыжка

Пока цель выбрана, отдельной строкой идёт то, что о системе знает EDSM — **до**
прыжка, а не после: кто её открыл и когда, можно ли заправиться у главной звезды
(зелёным — да, оранжевым — нет) и трафик за сутки, неделю и всего. После прыжка
строка живёт 15 секунд и исчезает, при выборе следующей цели заменяется сразу.

Месяца и года EDSM не сообщает — их в API нет. И отсутствие системы в EDSM не
значит, что там никого не было: база собирается из загрузок игроков, поэтому
строка говорит «в EDSM нет данных», а по прибытии система проверяется заново.

### Всплывающие строки

Появляются под нижней строкой на несколько секунд и исчезают сами:

| Событие | Что показывает |
|---|---|
| **Подбор материала** | `+3 Вольфрам (Сырьевой, Редкость: 3)  Всего: 79` — своё слово, цвет и иконка на каждую категорию: **Сырьевой**, **Промышленный**, **Данные** |
| **Отказ в стыковке** | `Bainbridge Market: стыковка запрещена — слишком далеко от станции` |

Названия систем, товаров, материалов и станций берутся из журнала игры, поэтому
показываются на языке вашего клиента. Сам интерфейс переключается отдельно:
**трей → Язык → Русский / English**.

## Управление

Всё через значок в трее, рядом с часами. **Клик** по значку скрывает и показывает
оверлей, **правый клик** открывает меню:

* **Показать / скрыть HUD**
* **Открыть config.toml**
* **config: <путь>** — какой файл настроек используется и можно ли в него писать
* **Верхняя строка** и **Нижняя строка** — галочка на каждый блок
* **Монитор** — на каком экране показывать
* **Проверить обновления** и режим обновлений
* **Язык** — Русский или English
* **Выход**

Окно прозрачно для мыши, поэтому закрыть программу можно только через трей (или
`Ctrl+C`, если запускали из консоли).

---

## Настройки

Файл настроек: **`%APPDATA%\elite-hud\config.toml`**, открывается из меню трея.

В файле только то, что имеет смысл менять: положение и вид строки, шрифт и размер,
цвета, состав блоков, язык, строка о материалах, EDSM, режим обновлений. Остальное
работает на значениях по умолчанию и при необходимости дописывается руками —
полный список в [docs/FEATURES_RU.md](docs/FEATURES_RU.md).

**Настройки переживают обновление:** новый файл всегда создаётся в профиле
пользователя, а не рядом с программой. Какой файл используется сейчас, видно в
меню трея строкой `config:`.

## Чего в программе нет

Сознательно или по ограничениям самой игры:

* **Оверлея поверх эксклюзивного полного экрана** — невозможно, нужен Borderless.
* **Материалов на ногах (Odyssey)** — журнал не пишет событие подбора: предметы,
  компоненты и данные, которые вы собираете пешком, в нём не отражаются.
* **Трафика EDSM за месяц и год** — в API этих значений нет.
* **Прогресса ранга Империи и Федерации в реальном времени** — игра сообщает его
  только при входе.
* **Звука и уведомлений с рамкой** — вместо них одна строка события, которая
  исчезает сама.

## Если что-то не работает

* **Оверлея не видно** — проверьте Borderless (см. начало страницы), затем пункт
  «Показать / скрыть HUD» в трее.
* **Данных нет** — убедитесь, что игра запускалась хотя бы раз: журнал читается из
  `%USERPROFILE%\Saved Games\Frontier Developments\Elite Dangerous`.
* **Настройки не сохраняются** — посмотрите строку `config:` в меню трея: если
  файл недоступен для записи, программа скажет об этом и всплывающим сообщением.
* **Что-то ещё** — напишите в [issues](https://github.com/madne5/edhud/issues) и
  приложите лог `%APPDATA%\elite-hud\elite-hud.log`.

## Разработка

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
QT_QPA_PLATFORM=offscreen .venv/bin/python -m unittest discover -s tests -t .
```

Сборка Windows-версии делается на Windows:
`.venv\Scripts\python tools\build_exe.py --windowed`. Релиз выпускается тегом
`v<версия>`, дальше всё делает GitHub Actions.

Подробности для разработчика — в [docs/](docs/): состав функционала, что и откуда
берётся в журнале, список задач и отчёт аудита кода.
