## Невозможно или ограничено игрой

| Задача | Почему |
|---|---|
| Уровень «Плохой репутации» в реальном времени | `Statistics.Crime.Notoriety` есть в журнале, но событие `Statistics` пишется **один раз при входе** (11 раз на 11 `LoadGame`). Уровень — снимок на момент входа; в сессии меняются только штрафы |
| Ранг Империи/Федерации в реальном времени | События `Rank` и `Progress` игра пишет **только при входе в игру**, а `Promotion` приходит лишь в момент повышения. В ваших журналах: 11 `LoadGame`, 11 `Rank`, 11 `Progress` — по одному на сессию. Значит процент до следующего звания внутри сессии не меняется, и взять его неоткуда. Звание обновляется корректно с версии 0.5.0 (до неё повышения супердержав не сохранялись) |
| Подсчёт непроданных картографических данных | Журнал не сообщает, что лежит на руках. Подсчёт сканов с последней продажи давал меньше, чем было продано, на **каждой** продаже: тела, просканированные до начала журнального окна, продаются внутри него. Одна продажа 78 тел прошла через 14 секунд после предыдущей, без единого скана между ними |
| Полноэкранный эксклюзивный режим | Оверлей поверх него невозможен технически. В README указан безрамочный режим |
| Тихий запрос UAC при автообновлении | Установка в `Program Files` требует прав администратора. Обойти нельзя |
| Предупреждение SmartScreen | Неподписанный exe. EV-сертификаты перестали его снимать с 2024 года, бесплатный путь только через MSIX в Microsoft Store |

## Правила, которые мы установили

* **Не хукать процесс игры.** Frontier в статье поддержки (обновлена 17.03.2026) называет перехват процесса основанием для ограничений аккаунта. Чтение журналов в списке нет — архитектуру не менять.
* **Логика только по символам журнала** (`$Codex_Ent_..._Name;`), локализованные подписи — только для показа. Игра может быть на любом языке.
* **Никаких выдуманных чисел.** Если значение нельзя проверить — его не показываем, а пишем почему. Так появились отказы от картографии и от редкости Тааргоидов.
* **Проверять на реальных журналах**, а не на собственных ожиданиях: формула дальности, накопление биологии, первый след и подбор материалов сверены с данными игры.
* **Читать и `status`, и `conclusion`** из GitHub API: скрипт, считавший успехом всё, что не `failure`, однажды сбил диагноз.
